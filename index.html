Al Afrah Platform

Marketing site and content backend for Al Afrah Limited, a commercial & shopping-mall developer. The API was originally seeded under the working name “Green Estate” and the schema still carries that name.

Overview

Two independently deployable pieces in one repo: a Next.js marketing site (Al Afrah/) and a FastAPI content service (backend/) that feeds it projects, blog posts, team bios, and inbound enquiries through a versioned JSON API. Verified running locally on 2026-09-16.

Architecture

A conventional split: static-first rendering on the edge, content and auth behind a Python service with a repository layer between routes and the ORM.

Running it locally

  1. Backend

    cd backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\uvicorn main:app --host 127.0.0.1 --port 8000 --reload

  2. Frontend

    cd "Al Afrah"
npm install
npm run dev

  3. Or, both at once

    .\run_local.ps1
